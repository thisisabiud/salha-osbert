# SOUL Wedding — Osbert & Salha RSVP Website

A beautiful, elegant wedding RSVP web application for Osbert & Salha's reception on 18 July 2026.

## Features

- 🎉 Stunning Save the Date hero section with couple photo
- ⏱ Live countdown timer to the wedding day
- 👗 Dress code colour palette display
- ✅ RSVP: attending guests submit their name
- 🎥 RSVP: non-attending guests can record a video message (up to 30s)
- 🔐 Admin dashboard to view all RSVPs, export to Excel, and download videos

## Setup

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env
# Edit .env with your desired admin password

# 3. Start the server
npm start
```

The app runs at **http://localhost:3000**

Admin panel at **http://localhost:3000/admin**
